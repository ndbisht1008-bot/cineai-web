# Google AI integration: what is officially possible (checked 29 October 2026)

Sources: Google's own developer pages, read on the date above. Things change; re-check before paying.

## 1. Google Flow / Google AI Pro credits: **no official way for another app to use them**

- Google publishes **no Flow API**. Flow (labs.google/flow) is a subscription web app.
- Nothing in Google's developer documentation lets a third-party app spend a user's Flow / AI Pro credits.
  Developers who asked on Google's own AI forum got no such answer
  ([forum thread](https://discuss.ai.google.dev/t/have-credits-in-flow-google-labs-but-cannot-use-them-via-api/113064)).
- Third-party "Flow API" services exist (e.g. useapi.net). They drive a Flow account through its private web
  endpoints, are not Google products, and may break Google's terms. **CineAI Studio will not use them**, and will
  not reuse cookies or browser sessions.
- **What CineAI does instead:** an "Open in Google Flow" link (https://labs.google/flow). A video you make there
  stays in Flow. You can download it and add it to a CineAI project yourself as an imported clip, labelled
  "imported from Google Flow", never as generated by CineAI.

## 2. Gemini API video generation: **real, official, but paid only**

- Current model: **Gemini Omni Flash** (`gemini-omni-1.1-flash`), via the Interactions API
  ([video docs](https://ai.google.dev/gemini-api/docs/video), [Omni docs](https://ai.google.dev/gemini-api/docs/omni)).
  Text-to-video, image-to-video, first/last frame, subject references, extension up to 40 s, 16:9 or 9:16,
  360p to 4K (1080p/4K upscaled), generated audio, invisible SynthID watermark.
- The **Veo 3.1 preview models were shut down on 22 October 2026** (same page). GA Veo is offered through Google
  Cloud's enterprise platform (Vertex AI), which also needs billing.
- **Free tier: "Not available."** Paid price about **US$0.10 per second of 720p video**
  ([pricing](https://ai.google.dev/gemini-api/docs/pricing)): a 1-minute film is about US$6 (about ₹500).
  Paid tier needs Cloud Billing on a Google Cloud project (a card, prepayment).
- **Google AI Pro does not pay for API calls.** API billing is a separate Google Cloud account.
- Regional limits: no editing of images with minors, and no editing/extending uploaded videos, in the EEA,
  Switzerland and the UK. India is not on those lists.

## 3. Using the Gemini API from a browser app

- Google's **ephemeral tokens work only with the Live API** ("At this time, ephemeral tokens are only compatible
  with Live API"), and are minted by a backend ([docs](https://ai.google.dev/gemini-api/docs/ephemeral-tokens)).
  So there is no official keyless browser flow for video.
- The only backend-free option is **the user's own API key typed into the app**, kept in memory only (not saved
  unless the user asks), sent only to `generativelanguage.googleapis.com`, with a clear cost warning before every
  paid generation. The key can be restricted in Google Cloud Console to the Generative Language API and an HTTP
  referrer (the app's address). CineAI will never ship a shared key in the website.

## 4. Google Sign-In

- Official options: **Google Identity Services** (GIS, free, no backend, just an OAuth client ID) or **Firebase
  Authentication** (free Spark plan, adds a Firebase project).
- Recommendation: **GIS**. The app keeps projects in the browser (IndexedDB), so it needs identity only; Firebase
  adds nothing it would use.
- **Signing in with Google gives no AI credits.** It does not unlock Flow, Gemini API, or AI Pro features.
- Setup needs one free step by you: create an OAuth client ID in Google Cloud Console and add the website address
  as an authorised JavaScript origin. The client ID is public by design (not a secret).

## 5. The free real-video provider that works from a browser today

- **LTX-Video (Lightricks) on Hugging Face ZeroGPU**, already verified in this project (real motion, 3 s clips,
  14–23 s each). Tested 29 October 2026: the Space answers browser requests from
  `https://ndbisht1008-bot.github.io` (CORS allowed), so a static site can call it with the official
  Gradio JavaScript client. **No backend.**
- Limit: shared free GPU quota, about 2 GPU-minutes a day per internet connection (about 4 clips), about 5 with a
  free Hugging Face account. Hugging Face offers "Sign in with HF" OAuth for static sites (public app, PKCE, no secret).

## Summary

| Route | Real video | Cost | Works without a backend |
|---|---|---|---|
| Google Flow credits from another app | n/a | n/a | **Not officially possible** |
| Gemini Omni Flash, user's own key | Yes | ~US$0.10/s, billing required | Yes (user key in browser, with warnings) |
| LTX-Video via Hugging Face | Yes | ₹0, ~4 clips/day | Yes (verified CORS) |
| Google Sign-In (GIS) | No AI access | ₹0 | Yes |
